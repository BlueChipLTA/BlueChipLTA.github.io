VoiceRecorder: foreground microphone service

Package: com.bluechip.voicerecorder · Version 1.2.1 · Android 16 emulator.

This silent native Android screen capture demonstrates a user-initiated recording continuing while the app is in the background. The ongoing notification makes recording visible to the user. The user returns, pauses, resumes and saves the local recording.

Open MP4 video

  1. 0–5 s: start recording from the library and expand the recording controls.
  2. 5–13 s: leave the app; recording continues, with a microphone indicator and ongoing notification.
  3. 13–23 s: return to the app, pause, resume and save; the saved item appears in the library.

Captured with an isolated instrumentation test using disposable data. There is no audio track or personal recording content in this video. The demonstration uses the privateBeta debug flavor, which shares the recording service and UI with publicFree and disables Google services. FOREGROUND_SERVICE_MICROPHONE is used only for the recording session that the user starts.
